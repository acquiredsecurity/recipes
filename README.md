A personal collection of recipes — the keepers, the experiments, and the
ones worth making twice.

## How it's organized

Recipes live in folders by category, one markdown file per recipe:

```
recipes/
├── breakfast/
├── mains/
├── sides/
├── soups-and-stews/
├── desserts/
├── drinks/
├── salsa/
└── sauces-and-staples/
```

## Recipe template

Copy this into a new file to add a recipe:

```markdown
# Recipe Name

**Serves:** 4 · **Prep:** 15 min · **Cook:** 30 min

## Ingredients

- 1 cup ...
- 2 tbsp ...

## Directions

1. ...
2. ...

## Notes

- Substitutions, tweaks, and lessons learned from making it.
```
